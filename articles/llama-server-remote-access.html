llama-serverを外出先から使う方法

自宅PCで動くローカルLLMを、外出先のスマホや別のPCから安全に利用するための構成を整理します。

127.0.0.1のままでは外部から接続できない

llama-serverを--host 127.0.0.1で起動すると、接続できるのは同じPC上のアプリだけです。これはローカル利用では安全で扱いやすい一方、外出先の端末からは到達できません。

llama-server -m model.gguf --host 127.0.0.1 --port 8080

別端末から使うには、端末から自宅PCまでの接続経路を用意する必要があります。

主な接続方法

方法用途注意点
同一LAN自宅内の別PCやスマホ外出先からは利用できない
VPN許可した端末からの個人利用各端末へのVPN設定が必要
トンネルクラウド上の処理などから接続認証、公開範囲、利用規約の確認が必要
直接ポート公開インターネットから直接接続攻撃対象になりやすく、個人用途では避けたい

自分のスマホやノートPCから使うだけなら、まずVPN経由の構成を検討しやすいでしょう。

おすすめはVPN経由の接続

外出先の端末
VPN
自宅PC
llama-server

VPNを使うと、参加を許可した端末同士をプライベートなネットワークとして接続できます。llama-serverを不特定多数へ公開せず、自分の端末にアクセス範囲を限定できます。

0.0.0.0は「安全な公開設定」ではありません。
--host 0.0.0.0は外部インターフェースからの接続を受け付ける設定です。VPNやファイアウォールなどで接続元を制限したうえで使います。

接続前に確認するポイント

  • VPN上のIPアドレスだけからポート8080へ到達できるか
  • OSのファイアウォールで接続元を必要な範囲に限定しているか
  • スマホや別PCから/v1/modelsなど必要なAPIへ接続できるか
  • 不要なポート開放やルーターの転送設定が残っていないか

接続先クライアントには、VPN上の自宅PCのIPアドレスとポートを指定します。OpenAI互換APIを利用する場合のベースURLは、構成に応じて次のようになります。

http://VPN上のIPアドレス:8080/v1

利用するVPN製品やOSによって設定手順は異なります。製品の公式ドキュメントに従い、端末の参加承認やアクセス制御を設定してください。

GitHub Actionsなどから使う場合

GitHub Actionsの実行環境は自分のスマホやPCとは異なるため、個人端末向けVPNへそのまま参加できるとは限りません。外部サービスから呼び出す場合は、認証付きトンネルや自前の実行環境など、実行元に合う接続方法が必要です。

また、自宅PCが停止中ならローカルLLMも利用できません。継続利用する場合は、PCとllama-serverの起動、異常終了時の再起動、アクセスログの確認も運用に含めます。

まとめ

ローカルLLMを外出先から使う場合は、llama-serverのポートを直接インターネットへ公開するのではなく、VPNなどで接続できる端末を限定するのが基本です。

まず同一LAN内で動作を確認し、次にVPN経由へ広げると、問題の切り分けもしやすくなります。
